# Reporte Lighthouse

Este archivo queda preparado para capturar evidencia de rendimiento y buenas practicas.

## Como correr Lighthouse

1. Levantar Angular:

```bash
cd frontend
npm start
```

2. Abrir Chrome DevTools.
3. Ir a la pestana `Lighthouse`.
4. Ejecutar auditoria en modo desktop y movil.
