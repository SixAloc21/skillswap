Acerca de

Una comunidad para aprender intercambiando

SkillSwap demuestra una experiencia web completa con frontend Angular, backend Spring Boot y busqueda con Elasticsearch.

Objetivo del proyecto

La plataforma permite publicar habilidades, explorar ofertas, solicitar intercambios y revisar matches. El enfoque principal es mostrar una interfaz moderna, dinamica, navegable y adaptable.

01

Frontend

Angular organiza la aplicacion en paginas, componentes compartidos, servicios y modelos TypeScript.

02

Backend

Spring Boot expone endpoints REST para habilidades, solicitudes, contacto y notificaciones wearable.

03

Busqueda

Elasticsearch indexa habilidades para buscar por texto, descripcion, categoria, nivel y modalidad.
