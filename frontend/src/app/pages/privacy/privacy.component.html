Privacidad

Aviso de privacidad

Esta pagina explica como SkillSwap maneja la informacion dentro de esta version academica del proyecto.

Datos usados

SkillSwap solicita datos basicos como nombre visible, habilidad publicada, disponibilidad y mensajes de contacto para simular una plataforma de intercambio de habilidades.

Uso de la informacion

La informacion se utiliza para mostrar tarjetas, enviar solicitudes, filtrar resultados y responder mensajes enviados desde el formulario de contacto.

Busqueda e indexacion

Las habilidades se indexan en Elasticsearch para permitir busqueda por texto, categoria, nivel y modalidad. No se implementa autenticacion ni perfiles reales en esta entrega.

Alcance academico

El proyecto no procesa pagos ni informacion sensible. Los datos se usan solo para demostracion de interfaz, backend, buscador y adaptacion responsive.
